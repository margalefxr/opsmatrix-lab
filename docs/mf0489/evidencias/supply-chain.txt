# Cadena de suministro de la app (20/10/2026)

## pip-audit con el requirements.txt original
$ pip-audit -r layer3-services/app/requirements.txt
Found 2 known vulnerabilities in 1 package
Name  Version ID              Fix Versions
flask 3.0.3   PYSEC-2026-2151 3.1.3
Alias: CVE-2026-27205 / GHSA-68rp-wp8r-4726
Qué es: en algunos accesos a `session` Flask no añade la cabecera `Vary: Cookie`,
y un proxy con caché podría guardar una respuesta con datos de un usuario.
Para que afecte hacen falta: usar `session` + un proxy que cachee respuestas con cookies.

## Valoración
- La app no usa `session` ni cookies.
- Nginx no tiene caché (no hay proxy_cache en default.conf).
=> No explotable en OpsMatrix. Aun así se actualiza: cuesta poco y quita el ruido en futuras auditorías.
